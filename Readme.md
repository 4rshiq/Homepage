
## 🦇 The Signal

> *"The city streets are crowded for the holiday. Even with the rain. Hidden in the chaos is the element, waiting to strike like snakes. And I'm there too. Watching."*

This is the source code of my corner of the internet: a fast, dependency-light, dark-mode-ready personal homepage with a Gotham-noir personality. No frameworks to fight, no build step to break. Open `index.html` and you're in.

---

## ⚡ Features

| | |
|---|---|
| 🌗 **Dark / Light mode** | One-tap theme switch in the slide-out menu |
| 📱 **Fully responsive** | Drawer navigation on mobile, clean layout everywhere |
| 🎭 **Personality-first design** | Batman-themed hero with custom wallpapers and a quote block |
| 🧭 **Four pages, zero friction** | Home, About, Contact and Extra |
| 🚀 **Instant load** | Plain HTML, CSS and vanilla JS. No bundler, no build |
| 🔤 **Typography** | [Rubik](https://fonts.google.com/specimen/Rubik) via Google Fonts |

---

## 🗺️ The Batcave (Project Structure)

```bash
Homepage/
├── 📄 index.html      # Landing page: hero, quote, hobbies
├── 📄 about.html      # The nerdy side
├── 📄 contact.html    # Signal me
├── 📄 extra.html      # Bonus content
├── 🎨 style.css       # Custom styles and theme variables
├── ⚙️  app.js          # Theme toggle, dynamic footer year, interactions
└── 🖼️  img/            # Wallpapers, favicon and assets
```

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 + [Bootstrap 6 (alpha)](https://getbootstrap.com/) via CDN
- **Logic:** Vanilla JavaScript
- **Icons:** Bootstrap Icons (inline SVG)
- **Fonts:** Google Fonts (Rubik)

---

## 🎨 Make It Yours

Fork it, strip the Gotham, and drop in your own identity:

1. **Swap the images** in `/img` and update the `src` paths in `index.html`
2. **Edit the copy** in each `.html` file
3. **Tweak the theme** colors in `style.css`
4. **Add pages** by copying any `.html` file and linking it in the nav drawer

If you build something cool from it, I'd love to see it.
